# Syvhon Inspired Podcast

A static, responsive podcast and personal growth prototype.

## Run locally

Open `outputs/index.html` in a browser. The prototype has no build step or server dependency.

## Deploy to Render

This repository includes a Render Blueprint (`render.yaml`). Once the project is pushed to GitHub and GitHub is connected to Render:

1. In Render, choose **New → Blueprint**.
2. Select this GitHub repository.
3. Review the `syvhon-inspired-podcast` static site and apply the Blueprint.
4. Render publishes the `outputs/` directory and provides a public `onrender.com` URL.

The site is static. Reflections, intentions, and episode metadata currently use the visitor's browser storage and are not shared between visitors or backed up to an account. Audio files selected in the studio are not uploaded to a server in this prototype.
